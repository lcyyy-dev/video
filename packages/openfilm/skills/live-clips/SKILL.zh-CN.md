# 直播切片

从长直播、网络研讨会、课程或播客中选择完整观点，避免断章取义。

## 找到完整片段

读取 OpenFilm 手册并使用 `openfilm look` 检查完整录音。不能只根据文件名、缩略图或前一分钟选择内容。存在源分析索引时先读取。寻找包含引题、解释和结论的完整观点，记录准确的源文件范围、转写内容和选择理由。

删除等待、重复和无关段落，但不能删除改变含义的限定条件，不能拼接不相关时刻的句子。保留必要上下文，让成片不会误导观众。记录 `live-plan.json`，包括源范围、删除范围、字幕和输出检查。

## 组成片段

默认使用硬切和正常速度。保持人物、动作和原声清晰。字幕来自实际说话内容，在自然短语处拆分，保持安全区和可读性。补充画面只能来自提供的素材或项目，不能编造证据。

如果用户提供模板文案，按模板原文处理；除非明确要求，不压缩、改写或生成替代旁白。没有录音时不擅自使用模拟 TTS。

## 检查和交付

修改后运行 `openfilm look`。检查开头、每个剪切点、字幕边界、最后一句、音频混音和源范围。确认片段保留完整观点，不遮挡人物，也没有空白画面。只有用户要求时才导出 MP4 或剪映草稿；否则保留可编辑 OpenFilm 工程，并报告源范围、时长、字幕、音频限制和输出路径。
