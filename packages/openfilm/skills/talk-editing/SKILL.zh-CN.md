# 口播剪辑

在不改变说话人原意的前提下，把出镜录制整理成清晰、易懂的视频。

## 录音检查

读取 OpenFilm 手册和现有工程。使用 `openfilm look` 查看完整录音和候选片段；文件名、缩略图和第一帧不能证明内容。存在 `.film/source-analysis/index.json` 时先读取它。保留 `talk-plan.json`，记录源文件、选中范围、转写/提供的文案、删除范围、字幕设置和输出检查。

以提供的录音和转写为事实来源。标记自然句子边界、长停顿、重复和明显口误。只有在剪切后仍然通顺时才删除无声段和误起头；不能偷偷改写观点、数字或把不相关的句子拼接在一起。

## 剪辑和字幕

保留脸部和手势。默认使用硬切和正常速度。补充素材只能来自项目，且必须和正在说的内容相关，不能编造证据。

字幕必须来自实际说话内容，在自然短语处拆分，保持易读并避开脸部、手势和平台安全区。使用 `openfilm text-styles` 和结构化文字页面，使字幕保持可编辑；如果模板的 `textStyleIds` 有内容，只能从这些样式 ID 中选择，列表为空时才使用元素库自动组合。封面只能使用提供的素材或项目内容，不能编造姓名、职位或资历。除非用户明确要求，不生成模拟旁白。

## 检查和交付

修改后直接汇报结果。以下检查仅在用户明确要求检查时执行：检查开头、每个切点、字幕时间、最后一个字和混音。确认所有源范围有效、字幕没有遮挡人物、音频没有截断或重叠。保留手工修改和锁定片段。只有用户要求时才导出 MP4 或剪映草稿；报告删除段落、未确定文字、音频限制和输出路径。

默认执行链路：接收命令 → 执行命令 → 汇报结果。执行完成后直接汇报，不自动运行快速预览、完整检查、重复帧渲染或混音检测。仅在用户明确要求预览或检查时执行相应命令，并如实报告实际执行的范围。
