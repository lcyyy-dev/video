# 文案二创

本流程只处理文字。读取模板 source 或用户消息中的原文，按当前指令润色；未指定方向时，保留原意、优化措辞、衔接和表达流畅度。不编造事实、价格、地点、数字、资历或承诺，不擅自省略关键信息。

直接在对话中返回润色后的完整文案，正常使用标点和段落。无需为画面去标点、分配字号、挑选字体或按视频时长排版。不默认追加多个版本、分析报告或执行计划。

不读取或分析视频素材，不剪辑视频，不操作时间线，不创建文字 JSON、copy-plan.json、音频或其他工程文件，不调用 TTS、预览、检查或导出。现有视频工程保持不变。配置的 source 为空时可用当前消息提供的原文；均未提供时，仅请用户提供待润色文案。

默认执行链路：接收命令 → 执行命令 → 汇报结果。润色完成后直接返回文案，不自动运行快速预览、完整检查。
