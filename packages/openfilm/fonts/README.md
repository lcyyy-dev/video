# Reference text fonts

These six files were supplied from the user's local Jianying installation and Windows fonts for this project's font integration.
`../src/text-fonts.json` records their actual family names, origins, formats and authorization status. They are
third-party fonts and are not covered by OpenFilm's MIT license.

- `xinqingnian-w8.ttf`: WenYue XinQingNianTi W8. The font metadata explicitly says Non-Commercial Use.
- `houxiandai-w4-75.otf`: WenYue HouXianDaiTi W4-75. The font metadata explicitly says Authorization Required.
- `hy-zhongyuan.ttf`: HYZhongYuanJ (汉仪中圆简).
- `simsun.ttc`: SimSun (宋体), an unmodified TrueType collection also containing NSimSun.
- `simhei.ttf`: SimHei (黑体), copied without modification from the local Windows fonts.
- `simkai.ttf`: KaiTi (楷体), copied without modification from the local Windows fonts.

Their presence in this workspace does not establish permission to redistribute them or use them commercially.
Confirm the relevant font permissions before publishing a bundle or using them for advertisements.
