# 文字元素与抽取权重

从仓库根目录启动本地编辑器：

```sh
node packages/openfilm/examples/text-elements-server.mjs
```

打开 http://127.0.0.1:8793/examples/text-elements-preview.html 。页面读取真实 `packages/openfilm/src/text-elements.json`，修改有效权重后立即自动保存，无需点击按钮。连续修改会按顺序保存最新值。出现“已保存到真实元素库”表示写入成功，刷新会保留。无效配置不会覆盖文件；多页面发生冲突时需刷新再改。

后续自动抽取会读取该文件的最新权重，无需重启源码运行的程序。独立安装包使用其自身携带的元素库，修改仓库不会远程改变已分发安装包；新打包版本会携带保存后的权重。

双击 HTML 会自动跳转到本地编辑器，需先启动上述服务；未连接服务的页面禁止编辑，避免修改丢失。可导出 JSON 备份。字体使用项目内文件，本地服务仅监听 127.0.0.1。

字体按权重抽取。文字和描边先过滤对比度低于 3:1 的相近颜色组合，再按文字权重 × 描边权重归一化抽取。卡片显示各库基础占比，试抽结果显示实际组合概率。默认权重 1，0 禁用；负数、非有限数、全零或没有可用对比组合的配置会报错。明确指定的预设不参与权重抽取。

重新生成独立 HTML：

```sh
node packages/openfilm/examples/text-elements-preview.mjs
```
