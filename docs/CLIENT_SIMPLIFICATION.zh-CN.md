# 视频剪辑客户端精简范围

本轮目标是收窄现有客户端，删除当前广告剪辑用不到的实现，供后续继续调整。
没有在本轮新增逐句制作面板、TTS 服务、授权或云端部署。

## 保留

- Electron 桌面窗口、多项目标签、项目创建／本地打开／保存和项目库。
- 本地素材、可复用素材收藏、画面预览、时间线、字幕编辑、音量及剪辑操作。
- 本地 Codex 的连接、登录、程序定位、模型设置、使用量和连接诊断。
- Windows x64 安装包内置固定版本 Codex，更新由客户端统一管理；构建流程见 [Windows 安装包构建](WINDOWS_INSTALLER.zh-CN.md)。源码运行仍支持已有的本地 Codex 安装。
- 四种视频工作流：`ad-editing`、`talk-editing`、`copy-rewrite`、`live-clips`，以及文字样式库、字体、自定义样式及预览。
- 视频导出、剪映／CapCut 草稿、项目文件夹或 ZIP 备份。
- 撤销、版本历史、任务进度、错误提示、更新基础；日志诊断按需开启。

## 已删除的客户端实现

- 通用示例／社区界面、GitHub 项目导入界面及其下载状态逻辑。
- 技能安装、预览、提交、授权选择的界面及桌面 IPC；只保留四种内置视频工作流读取。
- 云端媒体服务、模型服务和自定义服务的配置页面及前端请求逻辑。
- 云端字幕转写、翻译的前端请求、状态和操作；保留已有字幕及译文的编辑和显示。
- 内置 Pi Agent、自带模型密钥管理、非 Codex Agent 的启动注册和对应依赖。
- 非 Codex 的模型请求日志采集、旧内置 Agent 基准工具。
- GIF、平台批量预设、透明素材、音频分轨、字幕文件、静帧和幻灯片等客户端导出表单及请求构造。
- 透明单片段导出的画面／时间线菜单和回调，Premiere／Resolve 的客户端导出选项。
- 与客户端四种工作流无关的上游技能及其封面文件，以及同步回整套上游技能的脚本。
- 网页编辑器中的桌面应用推广弹窗。

入口、页面、调用链和相关依赖一起清理，不使用 CSS 隐藏或开关维持旧客户端功能。
历史项目文件、素材和用户凭证不做删除或迁移；旧智能体偏好不会重新启用其他 Agent。

## 共享底层的边界

OpenFilm 的 CLI、格式解析、渲染、音视频处理和服务端导出工具有共同依赖，本轮保留这些基础。
CLI 中的通用服务接口和其他输出格式不等于客户端仍提供相应入口，也不作为客户端授权边界。
剪映复杂效果的原生可编辑性继续遵守已有兼容规范，不因界面精简提高兼容性承诺。

## 后续

下一阶段可在此客户端接入逐句文案、模拟配音、镜头和文字动画的制作面板。
云端 TTS、账号计费与授权在另行确定范围后接入。

## 本轮验证

- 全仓类型检查、前端和桌面界面构建、发布包检查通过。
- 桌面端、四种视频技能及字幕相关测试通过。
- 使用实际构建界面和本地 Studio 服务验证项目列表、Codex 设置、广告推荐及三类导出，无页面异常；Electron IPC 使用模拟对象，未调用真实 Codex 模型。
- 全量回归曾有三项旧技能断言，已更新并通过定向测试。另有两项失败涉及未改动的共享服务代码：自定义服务连接错误文案断言、并发同名素材导入。相关生产代码及测试与本轮修改前一致，仍需单独排查；全量回归尚未全部通过。
