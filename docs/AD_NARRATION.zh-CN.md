# 广告文案朗读

仅广告素材模板支持文案朗读。正文启用后可选择服务端开放的音色、调整 0.5–2 倍语速、试听正文前 100 字；保存后按正文原文生成旁白。文案二创保持纯文字润色，口播和直播切片不生成 TTS。

## 服务端配置

在 `services/auth-gateway/.env` 配置：

```dotenv
DOUBAO_TTS_API_KEY=火山语音控制台创建的密钥
DOUBAO_TTS_SPEAKERS=zh_female_vv_uranus_bigtts
```

多个已开通的 TTS 2.0 音色用英文逗号分隔。使用现有部署方式重新构建并启动 gateway 容器，环境文件中的密钥不得加入版本控制或安装包。

`POST /tts/voices` 与 `POST /tts/synthesize` 复用设备签名、短期凭证、重放防护和每次请求的 Keygen 设备授权验证。合成接口只接受 `text`、`speaker`、`speechRate`，固定访问火山 TTS 2.0 HTTP 接口，禁用重定向，不接受 URL、请求头、模型或输出路径。每句至多 2000 字符，每许可证最多同时 2 个请求、每分钟 30 次；试听也计入限制。TTS 不请求 sub2api，不消耗其用户额度。

## 客户端执行

剪辑会话的本机请求桥只开放受随机 Token 保护的 `POST /tts/generate`。此接口不采用调用者提交的文本或路径，只读取当前工程已保存的广告模板；未开启朗读或非广告模板直接拒绝。系统密钥与设备私钥不交给剪辑会话。

会话通过内置 `openfilm narrate` 命令调用，不依赖用户额外安装 Python 或 Node。可选 `openfilm narrate --duration 20` 指定近似目标秒数（1–1800），由本机请求桥验证并通过 `x-openfilm-target-seconds` 传递；命令不接受文字、URL、输出路径参数，只使用客户端注入的本机地址与独立旁白能力凭据。旁白凭据不能调用模型代理，模型代理凭据也不能调用旁白接口。

原生代码按完整句子生成音频，保留引号和中英文标点，用 FFprobe 测量真实时长，写入 `assets/narration/*.mp3`。不生成 VTT，不叠加自动字幕；画面文字使用模板生成的可编辑文字轨道，并按旁白起止时间安排。字词时间戳只保存在音频缓存 JSON 中用于对齐；历史旁白 VTT 不再作为字幕显示或导出。`.film/narration.json` 记录每句原文、音频路径、真实时长和建议起止时间，句间默认停顿 0.2 秒。

剪辑会话根据记录安排独立旁白音轨，默认将视频原声音量降至 0.15。文字样式修改复用音频；朗读文案、音色或语速变化使对应句子的缓存失效。缓存校验音频摘要并重新探测时长。失败保留已完成句子，重试复用；取消会终止正在进行的合成。生成期间模板改变则拒绝发布旧结果。

用户指定时长时先自动估算语速，一次合成后按真实音频时长编排，允许接近目标。禁止删字或截断音频；达到语速上下限仍偏离目标时说明偏差并保留全文，不反复合成卡秒。保留手工编辑及锁定轨道。旁白通过现有音频轨道参与预览、MP4 混音和剪映草稿导出，工程备份携带生成素材。

## 验证边界

自动测试覆盖授权、重放与撤销、固定上游、参数拒绝、分块解析、原生请求桥、正文保留、真实时长读取接口、无重复字幕、缓存、失败恢复、取消和路径链接拒绝。服务端未配置真实火山语音密钥时，不能把测试替身结果称为真实合成验收。还需使用真实密钥检查音质、完整朗读、客户端预览和最终导出。

浏览器界面交互验收：`node apps/desktop/scripts/tts-ui-acceptance.mjs`。此脚本使用明确的 IPC 替身，验证广告音色/语速设置、试听等待状态、关闭后禁止迟到播放、保存，以及文案二创没有朗读控件；不证明真实 Electron IPC 或火山服务可用。

真实媒体及导出验收：设置本机 FFmpeg/FFprobe 的 `PATH` 和 Chromium 运行库后，运行 `OPENFILM_TEST_TTS_EXPORT=1 node --test apps/desktop/src/narration.integration.test.mjs`。上游语音仍为测试替身，但实际执行设备签名授权、音频探测、MP4 导出、可搬运剪映草稿音轨及项目副本素材验证。

## 目标时长与语速换算

豆包 `speech_rate` 范围为 -50～100：0 为原速，-50 约 0.5 倍，100 约 2 倍。参考[官方 HTTP 接口文档](https://docs.volcengine.com/docs/doubao-voice/http-chunked-sse-unidirectional-streaming-v3?lang=zh)。

无历史音频时，以字母/汉字/数字字符数除以每秒 5 字，加每个逗号等停顿标点 0.12 秒估算原速音频长度；这是产品初始经验值，不是官方固定朗读速度。有同文案同音色历史结果时，优先将实际音频总长乘以原倍速，还原为原速基准。预留句间停顿后计算 `speech_rate = round((原速基准秒数 / 可用朗读秒数 - 1) × 100)`，限制到 -50～100。相同目标重试保持原估算基准，避免浮动引发重复合成。

`.film/narration.json` 的 `ratePlan` 记录目标、估算依据、语速、预计时长及是否触及限制；各句 duration/start/end 始终来自实际 MP3。未指定目标时继续使用模板中的手动语速。

2026-11-05 真实调用：上门体能教练文案共 183 字符（165 汉字、2 数字、16 标点）。同文案原速音频总长 32.808 秒，含 0.6 秒句间停顿为 33.408 秒。目标 20 秒换算 speech_rate=69，真实生成含停顿 20.76 秒，偏差 +0.76 秒（3.8%），原文完整保留。此数据验证该文案与音色，不保证所有文案均有相同误差。

同一文案无历史音频的首次估算：speech_rate=82，真实生成含停顿 18.888 秒，偏差 -1.112 秒（-5.56%）；同样完整保留正文。
