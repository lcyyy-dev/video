# 安装版运行数据

安装版（Electron `app.isPackaged`）关闭应用的 `logs/studio.log`、工程 `.film/logs` 下的每轮调试日志、模型请求日志和调试图片写入，并关闭内部 AI 运行诊断输出。开发版仍保留诊断能力。正常聊天记录、项目、素材、成片和导出草稿保留，交由用户管理。

内部 AI 会话数据保存在应用数据目录 `project-codex/<工程路径摘要>`。在软件内删除项目成功后，Studio 通知桌面端，关闭该项目的内部会话，再删除对应的私有运行目录；不清除其他项目或激活信息。项目正在生成时拒绝删除，不触发清理。仅关闭标签页、移除项目列表文件夹或忘记一个工程不等于删除工程。

异常残留指正常退出本应删除、但在进程崩溃、断电或强制结束时留下的临时文件，例如未完成的导出中间文件、部分写入文件。正常导出已有 finally 清理。已加入异常恢复：启动时及运行中每分钟检查应用数据目录中的 `temporary-registry`。只有软件登记过、所属进程已退出且登记超过一分钟的临时文件才会清理。检查原父目录的真实路径，拒绝路径重定向；保留活跃进程、未知文件和正式导出。清理使用异步文件删除，不写运行日志。


覆盖范围包括工程导出中间目录、系统临时导出目录、草稿/工程导出的 `.partial` 暂存目录、TTS 的临时 MP3 和每个 AI 会话的临时目录。正常完成时主动删除暂存内容并撤销登记；崩溃时由下一次启动/定时检查回收。已重命名为正式导出的文件不会被回收。未登记的历史文件不按名称猜测删除。

界面不显示引擎模型、推理档位或供应商标识：输入框底部状态栏与回复页脚均已移除对应标签和悬停提示，旧记录的模型元数据也不再渲染。普通服务错误使用面向用户的文案，开发请求详情不作为聊天页入口提供。后台仍使用原有服务配置，不改变实际调用链路。
