# 视频聊天权限边界

右侧聊天是视频剪辑入口。范围包括已导入素材的分析、广告文案、镜头排列、裁切时段、字幕文字、音轨安排和原生导出。它不提供编程、终端、账号查询或通用问答能力。

## 执行链路

1. 原生 IPC 验证发送页面、所属会话及当前标签页绑定的已登记工程。应用、账号目录及其父目录不能作为剪辑工程。每次分析、修改前再次检查，拒绝符号链接、硬链接和目录穿越。
2. 显式的凭据、源码、命令及绕过权限请求在本机提前拒绝。随后使用严格 JSON 的意图判断，拒绝无关任务和夹带越权操作的混合请求。关键词检查只是提前反馈，不承担最终执行授权。
3. 原生执行器调用固定的 FFprobe / FFmpeg 参数，提供素材编号、有限元数据及抽帧。媒体格式和协议有白名单，不能将改名播放列表当作素材追踪其他文件。Codex 的工作目录是私有空目录，不是工程目录。
4. Codex 仅返回结构化计划。原生代码重新验证全部字段、素材编号、时段、数量、文字样式、锁定内容及工程版本，再生成规范的影片和文字页面。计划没有命令、文件补丁、任意 HTML、字体路径或输出路径字段。
5. 导出进入现有原生队列。模型只可选择 `none`、`jianying`、`mp4`；目录来自用户的原生设置。仅在队列实际完成后显示导出成功。

## 模型与账号隔离

`video-planner-runtime.mjs` 为每个会话建立独立 `CODEX_HOME` 和空工作目录。视频规划使用客户端保存的 Sub2API 域名和用户 Key，由主进程在安全边界外转发；不会读取或继承本机 ChatGPT 登录缓存，也不会把 Sub2API Key 写入 Codex 配置。不会继承用户/工程的配置、MCP、插件、hooks、其他 skills、外部 API 密钥和 shell 启动变量；会话关闭后删除私有运行目录。

`video-app-server-proxy.mjs` 强制真实的 `read-only` / `never` 策略，拒绝命令、文件、登录管理、权限变更、旧会话恢复及自主后台任务等 RPC。不能只相信 ACP 中名为 `read-only` 的预设：适配器的该预设曾实际请求 `workspaceWrite`，现在在原生协议层覆盖为只读。

`video-model-gateway.mjs` 使用带随机能力路径的本机 HTTPS 网关，证书仅对该规划器生效，不安装到系统。自定义 provider 保留官方账号认证，上游固定为官方服务；拒绝其他路由、浏览器 Origin、WebSocket 升级和重定向。推理请求移除全部工具及延迟工具定义；响应完整缓存检查后才交回 Codex，包含工具调用的响应直接拒绝。异常时停止执行，不回退到通用 Agent。

界面不展示模型的任意推理、工具内容或原始错误；展示原生进度、固定的视频补充提示、拒绝提示及实际执行结果。通用 `/` 命令菜单与权限切换被禁用。旧的通用 Agent 记录不会恢复进视频会话。

## 打包与范围

- Windows 安装包携带固定版本的 Codex 和本项目原生代码；发布脚本只复制源程序、构建资源及固定依赖，不复制开发者的 `.codex`、`.dev`、登录文件或个人 Gmail 会话。安装后的账号配置在每位用户自己的应用数据目录。
- 若未来改成开发者统一支付 API 费用，应由服务端保管密钥；不要把共享密钥或个人登录缓存写入安装包。当前实现使用宿主已登录的 ChatGPT 账号。
- 支持结构化视频、图片、音频和原生文字。自定义脚本、任意 HTML 动画、复合文字页面、外部字体和不支持的片段属性会明确拒绝处理；不能为兼容旧工程而重新开放终端。
- 这是产品聊天入口的能力限制，不是阻止本机所有者修改安装程序或读取自己账号文件的 DRM。素材解析器、Electron 和 Codex 仍需要随发布维护。意图分类可能误判，但分类结果不能授予执行器白名单以外的能力。
- 当前实际验收环境为 Linux / Electron、Codex 0.164.0。Windows 安装包固定版本为 `scripts/codex-build.json` 中的 0.156.1，仍需在真实 Windows 安装环境复测登录、证书、中文/空格路径、退出清理和剪映内打开草稿后再发布。

## 验证记录

客户端 155 项测试通过，覆盖真实媒体解析、播放列表伪装、路径/链接越界、工具剥离、恶意响应、TLS、环境与认证隔离、跨页面会话、锁定内容及并发边界。桌面端与共用编辑器类型检查、客户端构建通过。

真实账号验收位于本机 `.dev/restricted-video-flow/security-acceptance.json`（不纳入 Git）：完成生成和连续改色；4 类显式越权、无关问答、混合编程请求和开启完整权限均被拒绝；软件源码及原素材哈希不变。

真实客户端原生 IPC 与导出验收位于同目录 `desktop-security-acceptance.json`：启动返回 `video-only-v1`、无通用命令及模式选择；应用目录、凭据查询、完整权限请求被拒绝；导出完成，草稿含 2 秒视频和原生可编辑文字两条轨道，复制素材与原文件哈希相同，无页面异常。测试标签页关闭后返回原工程，保留浅色主题。本环境未在剪映应用中打开草稿。
