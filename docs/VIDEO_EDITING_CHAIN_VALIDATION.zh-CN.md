# 视频剪辑与剪映导出链路验证

验证日期：2026-10-20。先验证剪辑、渲染和工程导出，暂不继续开发客户端检查器。

## 结论

基本广告剪辑链路已验证：本地素材裁剪排列 → 结构化文字及三款内置字体 → 配音与音乐混合 →
1080×1920、30 FPS MP4 → 独立轨道的剪映草稿。复杂效果有明确预渲染限制，不能称为全部原生可编辑。
本次实际生成文件并解析检查；用户随后确认已看到文字可以设置。其他效果尚未逐项完成剪映界面验收，
不能把 JSON 检查等同于完整界面验收。

## 实际样片

1. **健身宣传15秒-内置字体链路验证**：4段视频、4段文案，1条主视频轨、1条文字轨、1条配音轨、1条音乐轨。
   三种字体为文悦新青年体 W8、文悦后现代体 W4-75、汉仪中圆简。文案沿用对应动作的已有选片方案。
2. **健身剪辑20秒-效果兼容性验证**：补充1.25倍速、文字动画、字幕、两种转场、画中画、视频关键帧。
   多轨仅用于对照验证，不作为简洁广告工程的默认轨道结构。

使用现有本地视频、配音及音乐，无付费 API。本次复用配音，不代表已接入新的 TTS 服务。

## 范围规则的真实状态

字体候选、按画面配色、深字白边／亮字黑边、描边／背景／阴影建议范围已经写入
`packages/openfilm/src/text-style-generation-rules.json`，通过 `text-styles generation-rules` 可读取。
背景和阴影按画面需要启用；数值是建议，参考剪映面板，不是像素硬限制。

**本次样片验证具体预设，不代表自动选参已经全部实现。**生成命令本身不分析画面；当前由AI读取规则、选取具体设置。
剪映面板值到预览／草稿的粗细、模糊、距离、角度和圆角换算尚未校准。结构化文字还缺少背景、圆角、描边独立透明度。
这些项目没有假装成功，也没有在样片中静默省略后声称验证通过。
